About

I am a Computer Science student specialising in Artificial Intelligence and Machine Learning. My work sits at the point where a trained model has to become a usable product: I build computer vision and predictive models, and I put the engineering around them, including APIs, interfaces and clear documentation, so that other people can actually use the result.

I am especially interested in two questions. How can models perceive the physical world, such as recognising waste from an image? And how can their predictions be made understandable, so that a result can be questioned and trusted rather than just accepted?

I am currently looking for internship and entry-level opportunities in machine learning and software engineering, and I welcome collaboration on projects in these areas.

How I Work
Start with the problem. I define what a model or feature must achieve before choosing an architecture.
Evaluate honestly. I validate models on held-out data and report results as they are, including the weak spots.
Make results explainable. Where a decision matters, I want to be able to show why the model made it.
Keep the code modular. Clear structure and readable code make projects easier to extend and review.
Ship something usable. A model is only useful once it is reachable through an interface or an API.
